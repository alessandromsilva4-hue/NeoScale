# 🟢 NeoScale

## Sistema Inteligente de Pesagem para Buffet por Quilo

O **NeoScale** é um sistema de autoatendimento para restaurantes e buffets, desenvolvido para controlar a pesagem das refeições, calcular valores automaticamente e emitir comandas de forma rápida e inteligente.

---

## 🚀 Funcionalidades

### ⚖️ Pesagem Inteligente
- Controle de peso da refeição
- Cálculo automático pelo valor do quilo
- Exibição do peso e valor final
- Preparado para integração com balanças digitais

---

### 🖨 Emissão Automática de Comanda

A comanda apresenta:

- Nome do sistema
- Peso da refeição
- Valor total
- Mensagem de agradecimento
- Frases de escritores e poetas
